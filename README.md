A fast drop-in for csv-reader 1.0.0: solve.js answers every broken-CSV case exactly as the reference does — same columns, rows and errors, stray CRs, quote junk, unterminated quotes and all — but reads the text in long jumps (indexOf and single-scan slices) instead of a character at a time, so the same answers cost a fraction of the CPU.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
